Sobre este projeto

Modelo de negócio e visão de produto

Este é um projeto de portfólio, mas foi desenhado pensando em viabilidade comercial real. Veja como ele poderia escalar.

Como ganha dinheiro

Modelo de afiliados: o site é gratuito para o usuário. Quando ele clica em um card (passagem, hotel, carro, seguro) e completa uma reserva no parceiro, o site recebe uma comissão.

Hoje os links levam diretamente para Booking.com, Google Flights, SegurosPromo, etc. Em um cenário comercial, cada URL incluiria um ?aid=ID de afiliado para rastrear conversões.

Comissões médias do mercado

  • Booking.com (hotéis)3-7% / reserva
  • Skyscanner (passagens)R$ 5-15 / clique
  • RentCars (aluguel)7-12% / aluguel
  • SegurosPromo (seguro)15-30% / prêmio
